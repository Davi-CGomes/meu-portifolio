# Portfólio — Davi Gomes

Portfólio pessoal desenvolvido para apresentar minha trajetória acadêmica e profissional, habilidades técnicas, experiências e principais projetos nas áreas de desenvolvimento de software, dados e inteligência artificial.

## Sobre o projeto

Este projeto foi desenvolvido utilizando Vue.js e Vite, com foco em uma interface moderna, responsiva e organizada.

O portfólio apresenta:

- Minha apresentação profissional
- Habilidades e tecnologias
- Experiência profissional
- Formação acadêmica
- Projetos desenvolvidos
- Formas de contato

## Tecnologias utilizadas

- Vue.js
- JavaScript
- HTML5
- CSS3
- Vite

## Projetos apresentados

### Análise do Mercado Imobiliário

Projeto de análise de dados sobre o mercado imobiliário de Petrolina/PE.

Utiliza técnicas de Web Scraping para coleta de dados e ferramentas de Python para tratamento, exploração e análise dos dados.

**Tecnologias:**
- Python
- Requests
- Matplotlib
- Pandas
- BeautifulSoup
- Web Scraping

### Machine Learning com Python

Projeto de Machine Learning utilizando o conjunto de dados do Titanic.

O projeto envolve análise exploratória dos dados, tratamento dos dados, engenharia de atributos e aplicação de algoritmos de Machine Learning para classificação.

**Tecnologias:**
- Python
- Pandas
- Scikit-learn
- Jupyter Notebook

### Flappy Bird com Inteligência Artificial

Projeto desenvolvido em Python no qual um agente de inteligência artificial aprende a jogar Flappy Bird.

O projeto utiliza neuroevolução para evolução das redes neurais e treinamento do agente ao longo das gerações.

**Tecnologias:**
- Python
- Pygame
- NEAT
- Redes Neurais
